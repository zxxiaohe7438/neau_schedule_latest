========================================================
  NEAU Local Schedule — 项目功能介绍
  东北农业大学个人课表管理软件（纯本地运行）
========================================================

一、项目简介
--------------------------------------------------------
面向东北农业大学学生的个人课表管理桌面软件。
完全本地运行：课表数据保存在本地 SQLite 数据库，
不联网、无账号系统、无云同步、不保存任何密码。
唯一允许的联网行为是用户主动触发的「官网获取课表」，
且仅连接学校官方域名（*.neau.edu.cn）。


二、核心功能
--------------------------------------------------------

1. 学期管理
   - 新建学期（名称 / 开学日期 / 总周数，自动生成默认节次时间表）
   - 学期切换（顶部下拉）
   - 归档 / 取消归档 / 删除学期
   - 清空全部数据（删除所有学期，需二次确认，不可恢复）

2. 课表展示（周课表）
   - 周课表网格：7 天 × 节次，跨节课程自动合并单元格
   - 课程格信息：课程名 / 课程编号 / 教师 / 上课地点 / 单双周 / 备注标记
   - 周次导航（上一周 / 下一周），当前周自动定位
   - 单双周过滤（单周 / 双周课程按当前周显示）
   - 今天日期高亮
   - 鼠标悬停：课程格发光特效 + 完整信息浮层（含学分、课程号等）
   - 双击课程格 / 空格子直接编辑；右键菜单（编辑 / 设置提醒 / 添加备注）
   - 无日程课程面板（网课 / 选修等无固定时间的课程）

3. 课程列表
   - 按课程分组展示：课程名 / 课程编号 / 教师 / 课时安排明细
   - 每节课的星期 / 节次 / 地点 / 周次 / 备注
   - 编辑课程、删除课程、编辑课时、删除课时

4. 课表导入
   - 官网获取：打开登录窗口 → 你在窗口内登录教务系统（扫码 / 账号 / 微信均可）
     → 手动进入课表页 → 点击窗口右下角「我已就绪，开始抓取」
     → 自动抓取本学期课表（支持校内入口与校外 WebVPN 入口）
   - 导入 JSON：选择 json 文件（含导出器生成的课表文件）
   - 智能粘贴：粘贴考试时间 / 课程信息文本，自动识别（如
     "6月15日(周一) 14:00-16:00 数据库原理 成栋楼A101"）
   - 导入预览：确认前展示学期信息、课程清单、错误与冲突

5. 导入模式
   - 覆盖导入（默认）：清空目标学期现有课程 / 事件 / 备注后全量导入
     （确认前有醒目警示 + 二次确认）
   - 合并导入：保留现有数据，重复项自动跳过，冲突项逐个裁决
     （保留本地 / 覆盖为导入 / 跳过）
   - 手动修改过的数据不会被静默覆盖

6. 格子备注
   - 双击课表空格子添加备注（颜色 / 内容）
   - 9 种预设颜色，备注按周次与单双周过滤显示
   - 可对备注单独设置提醒

7. 提醒系统
   - 默认提醒：课程 / 备注上课前 N 分钟提醒（提前时间可配置）
   - 自定义提醒：针对具体课程事件设置任意时间（预设快捷 / 精确时间）
   - 应用内 Toast 弹窗 + Windows 系统通知
   - 提醒设置面板（总开关 / 提前分钟数 / 桌面与应用内通知开关 / 测试按钮）

8. 备份与恢复
   - 学期备份：每学期导出 JSON 备份文件（手动选择保存位置）
   - 恢复备份：选择备份文件恢复（恢复前自动生成当前数据备份）
   - 备份文件包含学期、课程、课时安排、节次时间

9. 外观与主题
   - 赛博朋克风格 UI（液态玻璃质感、霓虹光效、扫描线纹理）
   - 亮色 / 暗色模式一键切换
   - 课程配色：同名课程共享颜色、不同课程互不重复（自动分配）
   - 自绘无边框窗口（可拖拽移动、最小化 / 最大化 / 关闭）

10. 开发模式（仅开发环境）
    - 加载测试数据：一键生成示例学期与课程
    - 官网抓取模拟：离线演示完整抓取流程


三、快速上手
--------------------------------------------------------
1. 启动软件，点击「+ 新建学期」创建学期（名称 + 开学日期）
2. 获取课表：
   - 校内：点「官网获取」→ 校内入口 → 登录 → 课表页 → 「我已就绪」
   - 校外：点「官网获取」→ WebVPN 入口 → 登录 → 教务系统课表页 → 「我已就绪」
   - 或点「导入 JSON」选择课表 json 文件
   - 或点「智能粘贴」粘贴文本自动识别
3. 预览确认（默认覆盖导入）→ 课表显示
4. 双击课程格可编辑；双击空格子可添加备注；右键可设置提醒


四、数据存储与安全
--------------------------------------------------------
- 数据库：%APPDATA%\neau-local-schedule\data\schedule.db（SQLite）
- 备份：%APPDATA%\neau-local-schedule\data\backups\
- 学校登录会话：加密保存（可关闭「记住登录」，关闭即清除）
- 不保存账号密码；密码只在你手动登录时输入，不经过程序代码
- 清空全部数据 / 删除学期 / 覆盖导入均需二次确认，操作不可恢复，建议先备份


五、技术说明
--------------------------------------------------------
- Electron + React + TypeScript + Vite
- SQLite（sql.js 纯 JS 实现，无需原生编译）
- 数据全部本地存储，可断网使用
- 支持 Windows 平台（NSIS 安装包）
