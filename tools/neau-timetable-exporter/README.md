# NEAU Timetable Exporter

独立导出器，用于从东北农业大学教务系统导出课表为 JSON 格式。

## 推荐流程

1. 用户手动登录学校教务系统
2. 在浏览器中打开课表页面
3. 保存课表页面为 HTML 文件
4. 使用本工具将 HTML 转换为 `timetable.json`
5. 在主软件中导入 `timetable.json`

## 注意事项

- 本工具不自动登录学校系统
- 不保存任何账号密码
- 不绕过验证码
- 用户需要手动完成登录和页面保存

## 后续计划

可以使用 Playwright 实现半自动导出：
- 用户手动完成登录和验证码
- Playwright 自动导航到课表页面并导出
