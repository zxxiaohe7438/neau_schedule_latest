# 具体实现任务

## 1. 实现 courses 数据层

实现基础 CRUD：

* createCourse
* listCoursesBySemester
* updateCourse
* deleteCourse

课程字段至少包括：

* id
* semester_id
* name
* teacher
* color
* created_at
* updated_at

要求：

* 数据库访问必须通过 repository 封装。
* React 组件不得直接访问数据库。
* Electron main process 负责数据库操作。
* preload 只暴露必要、安全、类型明确的 IPC 方法。

## 2. 实现 course_events 数据层

实现基础 CRUD：

* createCourseEvent
* listCourseEventsBySemester
* listCourseEventsByCourse
* updateCourseEvent
* deleteCourseEvent

课程事件字段至少包括：

* id
* course_id
* weekday
* start_section
* end_section
* start_week
* end_week
* week_pattern
* location
* note
* source_hash
* updated_manually
* created_at
* updated_at

week_pattern 只能是：

* all
* odd
* even

## 3. 默认课程颜色分配

实现稳定颜色分配函数。

建议路径：

src/utils/courseColor.ts

要求：

* 同一课程名每次得到相同颜色
* 不同课程尽量颜色不同
* 颜色不要太刺眼
* 适合课表背景展示
* 不要依赖网络资源

## 4. 实现 SemesterSwitcher

组件路径：

src/components/SemesterSwitcher.tsx

要求：

* 显示当前学期
* 可以切换学期
* 可以看到归档学期
* 先实现基础 UI
* 数据来自已有 semester repository / IPC

## 5. 实现 TimetableGrid

组件路径：

src/components/TimetableGrid.tsx

要求：

* 使用 CSS Grid
* 左侧显示节次和上下课时间
* 顶部显示星期一到星期日
* 顶部显示日期，基于学期开始日期和当前周计算
* 支持当前周切换
* 不同课程使用不同背景色
* 长课需要跨多个节次显示
* 空白格保持简洁
* 今天高亮
* 课程块至少显示：

  * 课程名
  * 地点
  * 教师
  * 周次范围
  * 备注提示

## 6. 实现 CourseListView

组件路径：

src/components/CourseListView.tsx

要求：

* 列表展示所有课程事件
* 字段包括：

  * 课程名
  * 教师
  * 地点
  * 星期
  * 节次
  * 周次
  * 单双周
  * 备注
* 先实现展示和删除
* 编辑功能可以先预留按钮，Day 3 再完善 CourseEditor

## 7. mock 数据验证

添加 mock 数据或开发模式种子数据，用于验证 UI。

至少包含：

1. 普通单节或两节课

3. 不同星期的课程
4. 不同课程颜色

要求：

* mock 数据不要污染正式数据库，或者提供明确的开发模式入口
* 可以用 fixture 或 seed 脚本
* 文档里说明如何触发 mock 数据
