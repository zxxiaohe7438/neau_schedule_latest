# 产品流程

## 在线流程

1. 用户点击“从学校系统获取课表”。
2. 软件显示说明：
   - 需要联网
   - 用户手动登录
   - 软件不保存账号密码
   - 不绕过验证码
   - 只获取本人课表
3. 软件启动 Playwright 浏览器。
4. 打开东北农业大学学生系统入口。
5. 用户手动登录。
6. 用户进入课表页面。
7. 用户点击“我已进入课表页面，开始读取”。
8. 软件读取当前页面 HTML。
9. 软件检查已捕获的 Network response。
10. 软件优先从 index / JSON response 中提取课表。
11. 如果 Network 里没有可用数据，再尝试从当前页面 HTML / script / window state 中提取。
12. 成功后生成 timetable.json。
13. 进入 ImportPreview。
14. 用户确认导入。

## 离线流程

1. 用户在浏览器 F12 Network 中找到 index 文件/响应。
2. 用户保存 response body 或复制内容到文件。
3. 在软件中点击“导入 F12 index 文件”。
4. 软件解析这个 index 文件。
5. 生成 timetable.json。
6. 进入 ImportPreview。

# 任务 3：实现多策略提取

在 schoolIndexImporter.ts 或独立文件中实现：

extractTimetableFromIndexContent

输入：

- content: string
- sourceName?: string

输出：

- timetableJson 或 normalized result
- errors
- warnings
- extractionMethod

解析优先级：

1. direct-json
   - 如果 content 本身是 JSON，直接解析。
   - 自动递归搜索疑似课程数组。

2. html-script-state
   - 如果 content 是 HTML，搜索 script。
   - 尝试提取 window.__INITIAL_STATE__、__NUXT__、__NEXT_DATA__、initialState、store、state 等变量。
   - 从这些 JSON-like 数据中搜索课程字段。

3. js-embedded-json
   - 如果 content 是 JS 或 index bundle，尝试搜索 JSON 片段。
   - 递归查找包含 course、lesson、timetable、kb、kcb、xq、jc、zcd、skdd、teacher 等字段的对象。

4. html-table
   - 如果页面里有 table，则复用或调用 htmlImporter。

5. page-text
   - 最后尝试按文本行解析。

6. failed
   - 无法解析时返回清晰错误，不要崩溃。
