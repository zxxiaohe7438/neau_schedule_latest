# Day 5 目标

今天只实现：

1. 学期归档
2. 历史学期查看

4. 删除前提示备份
5. JSON 备份导出
6. JSON 备份恢复

# 任务 1：学期归档

实现：

1. 当前学期可以归档。
2. 归档后的学期仍然可以查看。
3. 归档学期默认不显示在当前学期列表最前面。
4. 可以取消归档。
5. 归档操作必须持久化到 sql.js 数据库。

UI 要求：

- SemesterSwitcher 或学期管理区域显示归档状态。
- 提供“归档 / 取消归档”按钮。
- 操作后刷新 UI。

# 任务 2：历史学期查看

实现：

1. 可以查看所有历史学期。
2. 切换历史学期后，TimetableGrid 和 CourseListView 显示对应学期数据。
3. 历史学期数据只读或可编辑都可以，但如果可编辑，必须正常持久化。
4. 不要因为切换学期丢失当前数据。

# 任务 3：删除学期

实现：

1. 可以删除学期。
2. 删除前必须弹出确认。
3. 删除前必须提示用户先备份。
4. 删除学期时，需要删除该学期下的：
   - courses
   - course_events
   - section_times
   - import_batches
5. 删除操作不得影响其他学期。
6. 删除后必须持久化。

# 任务 4：JSON 备份导出

实现备份导出功能。

备份内容至少包括：

- semesters
- section_times
- courses
- course_events
- import_batches
- app backup version
- exportedAt

要求：

1. 用户可以选择导出位置，或先导出到 data/backups。
2. 文件名包含日期时间，例如：
   neau-schedule-backup-2026-06-01-1530.json
3. 导出的 JSON 应该可读。
4. 导出成功后提示路径。

# 任务 5：JSON 备份恢复

实现：

1. 用户选择备份 JSON。
2. 校验 backup version。
3. 预览将恢复的数据：
   - 学期数量
   - 课程数量
   - 课程事件数量
4. 用户确认后恢复。
5. 恢复前自动生成当前数据库备份。
6. 恢复后刷新 UI。
7. 恢复后数据必须持久化。
8. 如果备份格式错误，显示清晰错误，不要崩溃。

# 任务 6：Excel/CSV 简版导入

实现 xlsxImporter.ts 的简版。

优先支持 CSV，其次支持 xlsx。

如果当前项目已经有 xlsx 依赖，则可以使用。
如果没有 xlsx 依赖，不要为了它破坏当前稳定性；可以先实现 CSV，Excel 作为后续。

CSV 格式至少支持以下列名：

courseName,teacher,location,weekday,startSection,endSection,startWeek,endWeek,weekPattern,note

要求：

1. 可以导入 CSV 文件。
2. 可以转成 normalizer 统一结构。
3. 可以进入 ImportPreview。
4. 可以确认导入。
5. 可以显示到 TimetableGrid 和 CourseListView。
6. 失败时显示错误列表。

创建测试文件：

tests/fixtures/sample-timetable.csv
