```
· webvpn.neau.edu.cn → unexpected（{"status":"404","error":"Not Found"}）
· zhjwxs-443.webvpn.neau.edu.cn → unexpected   ← 无 preview = 空响应体
```
三个结论：
1. **教务系统映射域确认**：`zhjwxs-443.webvpn.neau.edu.cn`（深信服 `{内网主机}-{端口}.webvpn.neau.edu.cn` 域名映射格式）
2. **网络重放被 WebVPN 网关拒绝**：同一接口在登录窗口内由页面 JS 调用成功（用户看到了课表），但主进程 `net.fetch` 重放返回 **200 空 body**（preview 为空即空响应）——网关对非页面上下文的请求头/指纹挑剔
3. "已登录（open-weixin-qq-com-443…）"实为未验证状态（微信登录跳转残留域排第一），探测从未成功

## 解决方案：CDP 拦截真实响应（主数据路径）

不再依赖"重放请求"，改为**在登录窗口内直接捕获页面自身的接口响应**：
- `attachResponseCapture(webContents)`：`debugger.attach('1.3')` + `Network.enable`，监听 `Network.responseReceived`，URL 含 `ajaxStudentSchedule` 且状态 <400 时，延迟 300ms 调 `Network.getResponseBody` 取响应体
- 校验 JSON 含 `xkxx` 后存入 `capturedScheduleText` + 捕获域，`confirmLogin(host)` 并自动关窗（主窗口+弹窗）
- 登录窗口与弹窗均挂载；`logout` 时清空
- `school:fetchSchedule` 优先用捕获数据（解析 → 冲突检测 → 返回 ImportResult）；网络重放降级为兜底（校内直连等网关放行场景），失败时错误信息追加"重新打开登录窗口并进入课表页面"提示
- 诊断增强：空响应摘要显示 `(空响应)`

### 风险与说明

1. frameless 窗口无系统标题栏，拖拽移动靠 titlebar 区域；`-webkit-app-region: drag` 区域**不接收双击事件**，最大化请用右上角按钮（或后续加自定义双击处理）
2. 无系统窗口阴影（Windows frameless 不透明窗口无阴影）——以顶部青色底边线作为视觉边界
3. 若用户不习惯 frameless，回退只需 `frame: true` 一行
