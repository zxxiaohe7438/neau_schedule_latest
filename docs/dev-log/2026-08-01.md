# 2026-08-01 开发日志

## 任务
将 ZCode 的数据存储从 C 盘全部迁移到 D 盘，并确保后续数据默认写入 D 盘。

## 现状调查结论
ZCode 数据散落在 C 盘多处，且 CLI 路径解析部分硬编码 `os.homedir()`（→ `C:\Users\LEGION\.zcode`）：
- `C:\Users\LEGION\.zcode`（662MB）— CLI 的 db/log/rollout/exec/workflows 等，**活跃写入中**
- `C:\Users\LEGION\AppData\Roaming\ZCode`（30MB）— Electron userData（session/sentry/rum）
- `C:\Users\LEGION\AppData\Local\@zcodedesktop-updater`（249MB）— 更新器缓存
- `C:\Users\LEGION\.agents`（100KB）— agent skills
- 已配置的环境变量（`ZCODE_HOME=D:\ZCode`、`ZCODE_DATA_BASE_DIR=D:\zcode_data` 等）只覆盖部分路径；
  CLI 的 `db.sqlite`/`log`/`rollout` 硬编码 `homedir()/.zcode`，无法仅靠环境变量迁移。

## 方案
Windows 目录联接（junction）：真实数据放 D 盘，原 C 盘路径保留为 junction 指向 D 盘。
对运行中锁定的目录，通过计划任务在下次登录时（ZCode 未运行时）自动完成交换。

## 改动
- `D:\zcode_data\.zcode` — 合并了原 `C:\Users\LEGION\.zcode`（robocopy /XO，保留 D 盘更新版本）

- `D:\zcode_data\.agents` — 预拷贝
- Junction 已建立：
  - `C:\Users\LEGION\.agents` → `D:\zcode_data\.agents`
  - `C:\Users\LEGION\AppData\Local\@zcodedesktop-updater` → `D:\ZCode\appdata\Local\@zcodedesktop-updater`
- 脚本 `D:\zcode_data\zcode-migrate\finalize-migrate.ps1`（幂等）：
  停止 ZCode → 交换 `.zcode` 和 `Roaming\ZCode` 为 junction → 合并残留 → 旧数据移入
  `D:\zcode_data\zcode-migrate\backup\` → 自动重启 ZCode
- 计划任务 `ZCode-Migrate-To-D`：登录后延迟 20s 触发，状态 Ready
