# NEAU Local Schedule - 需求说明

## 概述

完全本地运行的东北农业大学个人课表管理桌面软件。

## MVP 功能

1. 学期管理 — 新建、编辑、删除、归档
2. 节次时间管理 — 默认 NEAU 时间表
3. 课程数据管理 — CRUD
4. 课表展示 — 周课表视图 + 列表视图
5. 导入功能 — JSON / HTML / 剪贴板 / Excel CSV
6. 导入预览 — 确认后才写入
7. 重新导入保护 — 不覆盖手动修改
8. 备份和恢复 — JSON 备份导出/导入

## 约束

- 纯本地运行，不联网
- 不保存学校账号密码
- 不绕过验证码
- Windows 桌面端
